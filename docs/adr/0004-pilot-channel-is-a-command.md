# crank-pilot's channel is a command the prose runs

The crank and crank-lite phase prose reaches the interactive page by running a `crank-pilot` command that a companion plugin puts on PATH, with the verbs show, wait, resolve, and close. A hook, a mod, or an MCP server was rejected because skill prose must stay harness-agnostic, and an earlier Claude-only mod around crank runs was retired. The cost is that the command is on PATH only in Claude Code, so the mode is Claude-only until another harness offers the same.
