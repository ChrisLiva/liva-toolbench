# liva-toolbench

The plugins and skills this marketplace ships, and the language their prose and code share.

## Language

**Interaction**:
One thing an agent posts to the crank-pilot page for the user to respond to: a question round, a readback, or a prototype review.
_Avoid_: request, prompt, step

**Interactive mode**:
A crank or crank-lite run that puts its question rounds, readback, and prototype review on the crank-pilot page instead of in chat.
_Avoid_: pilot mode, page mode

**Mark**:
One piece of user feedback on a readback: a comment on selected text, a strike on selected text, or a general note.
_Avoid_: annotation, comment (for the general case)
