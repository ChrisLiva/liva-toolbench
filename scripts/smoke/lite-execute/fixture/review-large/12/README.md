# ledger

A small household ledger. Standard library only.

    python3 -m ledger list
    python3 -m ledger import statement.csv
    python3 -m ledger categorize
    python3 -m ledger report --month 2026-09
    python3 -m unittest discover -s tests

[docs/index.md](docs/index.md) covers each command and file format.
